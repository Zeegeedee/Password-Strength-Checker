# Password Strength Checker & Generator
This project calculates how long it would take for a hacker to crack your password. This project could also generate a strong password for you.

## IMPORTANT
Install all required packages by running "setup.py".

## Features
- Can check if your password is vulnerable to dictionary attacks.
- Can check if your password is too short.
- Can check if your password is too common.
- Can check if your password is a mathematical constant.
- Can generate a strong password for you
- Can't give me your password; it stays on your computer so i can't hack you. Plus, how would i know what account you used it for plus I also don't know your username.
